# ImpaktMałopolska — outline 10 slajdów (PDF max 10)

Skopiuj do Google Slides / Keynote. Język: **polski**.

1. **Tytuł**  
   ImpaktMałopolska · Hub Innowacji Społecznych  
   Tagline: *Z głosu mieszkańców — gotowy wniosek do urzędu*

2. **Problem**  
   Oddolne inicjatywy giną. Urzędy dostają szum. Brak mostu: potrzeba ↔ sprawdzona innowacja ↔ formalny wniosek.

3. **Rozwiązanie (1 zdanie + flow)**  
   Mapa → upvote → AI matchmaking → wniosek art. 241 KPA → heatmapa instytucji

4. **Użytkownicy**  
   Mieszkańcy / NGO · JST · ROPS · eksperci

5. **Matchmaking (obowiązkowy)**  
   Screenshot karty innowacji + score · „podobny problem rozwiązano w X”

6. **Wniosek**  
   Screenshot wygenerowanego pisma + właściwy wydział

7. **Heatmapa / Social Twin**  
   Screenshot `/admin` · trendy dla Marszałka / radnych

8. **Dostępność i UX**  
   PL, duży tekst, kontrast, lista + mapa, WCAG-ish

9. **Tech + Opus 5.5**  
   Next.js, Leaflet, seed, API match/petition  
   *Budowaliśmy z Opus 5.5 jako asystentem implementacji i generatorem wniosków — walidacja i UX są nasze.*

10. **Wdrożenie / koszt**  
    MVP gotowe do pilotażu z Biblioteką Innowacji · niski koszt utrzymania · skalowanie województwa
